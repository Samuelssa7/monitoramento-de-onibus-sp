# 🚌 Monitoramento de Ônibus SP

Projeto desenvolvido em Python para consumo e manipulação de dados de monitoramento de ônibus da cidade de São Paulo.

## Objetivo

Coletar informações de monitoramento de ônibus em tempo real, realizar tratamento de dados e explorar integrações com APIs externas utilizando Python.

## Funcionalidades

* Consumo de dados via API;
* Tratamento de respostas JSON;
* Manipulação e processamento de informações;
* Organização de dados em Python;
* Estruturação de código em múltiplos arquivos.

## Tecnologias Utilizadas

* Python
* APIs REST
* JSON
* Requests
* Manipulação de Dados

## Aprendizados

Este projeto permitiu aprofundar conhecimentos em:

* Consumo de APIs REST;
* Tratamento de dados JSON;
* Organização de código em Python;
* Resolução de problemas e depuração;
* Integração de sistemas.
